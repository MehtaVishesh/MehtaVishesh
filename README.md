# Hey, I'm Vishesh Mehta

I'm a Software and AI Engineer based in Melbourne, Australia, with a Master's in Artificial Intelligence from Monash University. I build AI applications that combine large language models, tools, data retrieval, and structured workflows to solve practical problems.

My current focus is **AI agents, LangChain, LangGraph, and retrieval-augmented generation (RAG)**, with an emphasis on building applications that connect LLMs to external tools, documents, APIs, and databases.

### What I Work On

- **AI Agents:** Building tool-calling agents that search the web, interact with databases, and maintain conversational context.
- **Agentic Workflows:** Designing stateful workflows with LangGraph, conditional routing, structured outputs, and human-in-the-loop review.
- **Retrieval-Augmented Generation:** Developing document question-answering systems with embeddings, vector search, and contextual retrieval.
- **Data Engineering:** Building data pipelines with Python, SQL, and spatial data processing.
